# 🧮 Calculator App

A simple and responsive **Calculator Web Application** built using **HTML, CSS, and JavaScript**.  
This project performs basic arithmetic operations like addition, subtraction, multiplication, and division.

---
## Live link of Project:
 https://peetlamahesh123.github.io/CalculatorApp/

 ---
## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖ Multiplication
- ➗ Division
- 🧹 Clear Button (AC)
- ⌫ Delete Button
- 📱 Responsive Design
- ⚡ Real-time calculation

## 💻 How It Works

- User clicks numbers and operators.
- JavaScript captures the input.
- Expression is evaluated using JavaScript logic.
- Result is displayed on the screen.

---

## ▶️ How to Run the Project

1. Download or clone the repository:
   ```
   git clone https://github.com/PeetlaMahesh123/CalculatorApp.git
   ```
2. Open the project folder.
3. Double click `index.html`.
4. The calculator will open in your browser.
